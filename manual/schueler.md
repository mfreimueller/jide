# Schüler:innen und Codezettel

Schüler:innen haben in J;DE **kein Passwort und kein Konto**. Jede Person bekommt einen **persönlichen Code**. Mit diesem Code meldet sie sich in der App an.

## Namen eintragen

1. Öffnen Sie den Kurs und wählen Sie „Schüler:innen“.
2. Rechts steht die Karte „Schüler:innen hinzufügen“. Fügen Sie die Namen ein, **einen Namen pro Zeile**.
3. Der Knopf zeigt, wie viele Codes entstehen, zum Beispiel „6 Codes erzeugen“. Klicken Sie darauf.

![Namen einfügen](/images/schueler-hinzufuegen.png)

Jede Person bekommt automatisch einen Code. Er hat acht Zeichen und wird so angezeigt: `XXXX-XXXX`. Verwechselbare Zeichen wie 0 und O oder 1 und I kommen nicht vor. Groß- und Kleinschreibung ist egal.

## Die Liste

Die Tabelle zeigt für jede Person:

- **Name**
- **Persönlicher Code**
- **Zuletzt aktiv**. Wer sich noch nie angemeldet hat, ist mit „noch nie angemeldet“ markiert.
- **Abgaben**, zum Beispiel „2 / 3“. Das sind die Abgaben im Verhältnis zu den freigeschalteten Aufgaben.

![Schüler:innen eines Kurses (erfundene Namen)](/images/schueler.png)

## Codezettel drucken

1. Klicken Sie oben rechts auf „Codezettel drucken“.
2. Die Seite „Codezettel“ zeigt für jede Person einen Zettel mit Name, Klasse und Code. Die Zettel sind zum Ausschneiden.
3. Klicken Sie auf „Drucken“.

![Codezettel zum Ausschneiden](/images/codezettel.png)

Auf dem Zettel steht: „Öffne J;DE und gib diesen Code ein. Gut aufheben – nicht weitergeben!“

## Code zurücksetzen

Hat jemand den Zettel verloren? Klicken Sie in der Zeile auf „Code zurücksetzen“ und bestätigen Sie.

- Der **alte Code funktioniert sofort nicht mehr**.
- Die Person braucht den neuen Zettel.
- Bisherige Abgaben bleiben erhalten.

## Person entfernen

„Entfernen“ in der Zeile entfernt eine Person. Sie kann sich danach nicht mehr anmelden.

::: tip Gut zu wissen
Ein Code funktioniert auf mehreren Laptops gleichzeitig. Auf einem neuen Laptop sieht die Person ihre zuletzt abgegebene Lösung als Ausgangspunkt.
:::
