# Anmelden im Lehrer-Web

Im Lehrer-Web gibt es kein Passwort. Sie bekommen einen **Anmelde-Link per E-Mail**.

## So melden Sie sich an

1. Öffnen Sie die Adresse des Lehrer-Webs. Sie bekommen sie von der Person, die den Server betreut.
2. Geben Sie unter „E-Mail-Adresse“ Ihre Adresse ein.
3. Klicken Sie auf „Anmelde-Link senden“.
4. Öffnen Sie die E-Mail und klicken Sie auf den Link. Sie sind sofort angemeldet.

![Anmeldeseite des Lehrer-Webs](/images/anmelden.png)

Danach sehen Sie die Seite „Kurse verwalten“. Die Sitzung gilt 30 Tage. In dieser Zeit bleiben Sie angemeldet.

## Wenn etwas nicht klappt

- **Kein Link angekommen?** Schauen Sie im Spam-Ordner nach. Die Seite „Link wurde gesendet“ bietet „Link erneut senden“ an. Das geht nach einer kurzen Wartezeit.
- **„Dieser Link ist abgelaufen“.** Der Link gilt 15 Minuten und nur einmal. Klicken Sie auf „Neuen Link senden“.
- **„Dieser Link funktioniert nicht“.** Er wurde schon benutzt oder ist ungültig. Fordern Sie einen neuen an.
- **Ihre Adresse ist nicht registriert?** Dann kommt kein Link an. Lehrkräfte-Konten legt die Person an, die den Server betreut. Siehe [Selbst hosten](/selbst-hosten).

![Hinweis nach dem Senden des Links](/images/link-gesendet.png)

## Abmelden

Klicken Sie links unten auf „Abmelden“. Dort finden Sie auch „Kurse verwalten“ und „API-Schlüssel“.
